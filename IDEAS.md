# Ideas (not in PLAN.md — not built)

- App icon (`assets/app.icns`) and a `make icon` target, as in DocKit.
- Accept 2 channels after calibration (main + split left hand), if the user wants SPLIT on the YPT-320.
- A "MIDI test" that counts lost note-offs (stuck notes) for cheap cables (PLAN Section 15 risk).
- Warn when many notes are "wrong by 12" after calibration (TRANSPOSE/OCTAVE changed during practice).
- Show octave numbers on the keys as a setting, with the Yamaha naming (middle C = C3).
- Reset button for the delay statistics on the About screen.
- UI: a "Follow the Mac setting" theme choice (`prefers-color-scheme`), next to Dark and Light.
- UI: a short tour on the first start that points to the sidebar items.
- UI: keyboard shortcuts for the sidebar items (Cmd+1…Cmd+5).
- UI: color the keys left of middle C green and right of it blue in free play, as a hint for the hands (needs a lesson first).
- Wait mode with the mouse: click the screen keys as input (to try songs without the keyboard).
- Lyrics under the falling notes (PLAN 7.4 Rule 1 mentions song words) — needs a `words` field in the song format.
- Latency calibration for the click (PLAN 4: tap with the click) — the click is not corrected for audio output delay yet.
- Remember the practice options (speed, the click, count-in) per song.
- Ode to Joy part B (needs the low G: a hand move), as a Level 3 or 4 version.
- A short "Got it" card the first time a hand move or a spread hand appears (skill moments are Phase 3).
- Tempo map in the song format (imported songs with tempo changes play at one speed now).
- Delete or rename an imported song from the Songs screen (only "import again" replaces it now).
- Import screen: a small piano-roll preview of each track before the import.
- Import: drag a MIDI file onto the window.
- Hot-plug: a port that closes and opens again with the same name within 2 s is not seen again (found with 2 fake-player runs one after the other). Check with a real USB cable.
- Course: a "Start the course again" button (reset course progress, keep the songs and settings).
- Skill moments: check the timing of the tries with the click (Phase 4 timing data), not only the keys.
- Today: pause the block timer when the window is hidden.
- Words page: play the demo inside the card on the page (now it opens the card).
- Bar lines: an option to show them before Level 3.
- Practice time: also count watch mode (listening) as practice time.
- Play-along: detect "the user started the phrase again" (restart), not only a stop of 2 s.
- Findings also after wait-mode runs (hard spot from the wrong keys; wait mode has no timing).
- Automatic speed per song (now one speed setting for all songs; the adapt step changes it).
- "Practice these 3 keys" as a small drill (keys together, 3 tries) instead of a wait-mode loop.
- Progress page: show the reviews that are due on the Today screen as well, with the date.
- Skill model: a short history line for each skill (is it going up?).
- Audio import: optional source separation (demucs) and a piano-only model (piano_transcription_inference) as an extra download (not installed in Phase 5a; about 400 MB).
- Audio import: a tempo map (speed changes) from the beat tracker, instead of one speed for the whole recording.
- Song editor: copy and paste notes; a velocity (touch) lane; play only the selected notes; zoom with the trackpad pinch.
- Easy versions: keep more of the tune at Levels 1-3 with 2 or 3 hand positions (now one 5-finger position).
- Song list: a filter for "Your songs" (imported, easy versions, copies) and delete/rename.
